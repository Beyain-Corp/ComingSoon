# Coming Soon — Jebin Joseph J. Portfolio Theme

A clean, plain webpage with **Coming Soon** centered in the screen, styled to match the theme, typography, and aesthetic of [Jebin's Portfolio](https://beyain-corp.github.io/Jebin_Portfolio/).

## ✨ Features
- **Design System Match**: Identical fonts (`Plus Jakarta Sans`, `Inter`, `JetBrains Mono`), color scheme, and typography scale.
- **Theme Engine**: Complete support for both Light and Dark modes with smooth transitions and persistent state.
- **Visual Accents**: Subtly textured background grid (`48px x 48px`), soft cyan and indigo ambient glow blobs, and an emerald pulsing status pill.
- **Zero Dependencies**: Self-contained in a single file with external web font imports.
